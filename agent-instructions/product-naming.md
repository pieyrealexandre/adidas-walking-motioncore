# Product Naming Conventions

## Official Product Names
Always use the exact official product names as provided. Do not create variations or abbreviations unless specified.

### Formatting Rules
- Capitalize proper product names: "Ultraboost 24", "Samba OG"
- Include model numbers/versions when relevant: "NMD_R1", "Forum Low"
- Use "x" for collaborations: "adidas x [Partner Name]"

## Referring to Products in Copy

### First Mention
- Use full official name with brand
- Example: "The adidas Ultraboost 24"

### Subsequent Mentions
- Can use shortened version: "the Ultraboost" or "the Samba"
- Maintain consistency within same piece of copy

### Technical Descriptions
- Capitalize technology names: "Boost cushioning", "Lightstrike", "Primeknit"
- Use "featuring" not "with" for tech callouts

## Color Names
- Use official colorway names when available
- Capitalize color names in official colorways: "Core Black/Cloud White"
- Use descriptive names for non-official colors: "triple black", "grey and gold"

## Category References

### Footwear
- shoes (general)
- sneakers (casual contexts)
- footwear (formal contexts)
- silhouette (product design reference)
- kicks (casual contexts only, sparingly)

### Apparel
- Use specific item names: hoodie, tee, shorts, jacket, pants
- Use "apparel" for general category reference
- Avoid generic "clothing"

### Accessories
- Use specific item names: cap, backpack, socks, bag

## Brand Terms
- **adidas** is always lowercase, never "Adidas"
- **CONFIRMED** is always uppercase
- Capitalize product line names: "Originals", "Sportswear", "Performance"

## Avoid
- Nicknames unless officially recognized
- Slang terms for products
- Abbreviations not approved by brand
- Made-up colorway names
- Unofficial shortened names
